# WorkAgent production runtime payload

`components.json` is the exact runtime-scope component contract consumed by `workagent-release manifest`. `scripts/assemble-runtime-linux.sh` merges only separately verified component outputs. Every trusted input and every component of its absolute parent chain must be symlink-free, owned by UID/GID 0 and not writable by group or other users; artifact trees apply the same ownership, type and mode rule to every entry, closing the verify/copy replacement window. For every component the assembler then requires an externally pinned checksum of the artifact's own `SHA256SUMS`, proves that the strictly canonical manifest names every file exactly once with no extras, and verifies an externally pinned canonical tree hash that also binds paths, types and modes. It checks every version and checksum again, rejects collisions and releases that would exceed the release manifest's file-evidence limit, and copies this list into the payload as `components.runtime.json`.

The assembler also reruns the managed Codex ACP 1.1.2 fork/steer wire gate and checks the nested Node, Codex ACP, OpenAI Codex, Claude ACP, and Claude SDK license evidence. `scripts/smoke-runtime-linux.sh` starts the final AionUi host with its final AionCore and bundled resources, verifies frontend readiness, the proxied auth-status API, the exact backend health contract, process identity, and graceful parent/child shutdown. Its first-launch password stream is redacted before being written to retained evidence.

After the payload is mode-frozen, the assembler also requires the externally qualified hash of its generated complete `SHA256SUMS` and the externally qualified canonical hash of the entire pre-manifest tree. Those two pin files remain outside the payload, so this is a two-stage promotion lock rather than a self-referential hash. The output parent must already be a protected root-owned directory on the same filesystem as the private build directory. Publication uses an atomic no-clobber directory rename and verifies that no staging tree remains, so a raced destination cannot turn the payload into an unexpected nested directory. The assembled directory is immutable-ready but is not itself a verified release. Operators must install it as a protected root-owned release directory and create the unsigned manifest with the pipeline described in `deploy/README.md`. The assembler never invents that release evidence.
